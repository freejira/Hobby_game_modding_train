# lord_remover

자기 세력 군주를 **영구 삭제**. 레벨·불멸 여부 상관없이 삭제되고 고용창으로 돌아오지 않는다.
연방 후 쓸모없는 군주가 군주 풀을 차지하는 문제 해결용.

- 게임 버전: WH3 (최신 패치 기준, 인게임 테스트 필요)
- 의존 모드: 없음
- 비슷한 모드: Execute (useless) Lords & Heroes (워크샵 2958113532)

## 사용법
1. 지울 군주를 고용창에서 고용해 맵에 꺼낸다 (풀을 직접 건드리는 스크립트 API가 없음).
2. 맵에서 군주 선택 → 화면 하단 중앙 삭제 버튼을 **3초 안에 두 번** 클릭.
- 세력 지도자는 삭제 불가
- 군대에 유닛이 남아 있으면 삭제 불가 (실수 방지)

## 원리
`cm:suppress_immortality` 로 불멸을 끈 뒤 `cm:kill_character` 로 삭제.
클릭은 `UITriggerScriptEvent` 를 거쳐 처리 (멀티플레이 동기화).
